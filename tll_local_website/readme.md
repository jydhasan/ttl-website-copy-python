# TLL.com.bd - Offline Website Mirror

এই প্রজেক্টটি https://tll.com.bd/ ওয়েবসাইটের পুরো কপি লোকালভাবে ডাউনলোড করে অফলাইনে চালানোর জন্য তৈরি করা হয়েছে।

## বৈশিষ্ট্য (Features)

- সম্পূর্ণ ওয়েবসাইট ক্রলিং
- সব পেজের HTML ডাউনলোড
- ইমেজ, CSS, JavaScript সহ সব রিসোর্স ডাউনলোড
- লিংকগুলোকে অফলাইনের উপযোগী করে ফিক্স করা
- লোকাল ফোল্ডারে সুন্দর স্ট্রাকচারে সেভ
- CSV ও TXT ফরম্যাটে পেজ লিস্ট জেনারেশন

## প্রয়োজনীয়তা (Requirements)

- Python 3.8 বা তার উপরে
- ইন্টারনেট সংযোগ (ডাউনলোডের সময়)

### ইনস্টলেশন

```bash
pip install requests beautifulsoup4 lxml
```

## ব্যবহারের নিয়ম (How to Use)

### Step 1: সাইট ক্রল করুন

```bash
python crawl-ttl.py
```

### Step 2: পুরো ওয়েবসাইট ডাউনলোড করুন

```bash
python download_full_site.py
```

### Step 3: লোকাল ওয়েবসাইট চালান

ডাউনলোড শেষ হলে `tll_local_website` ফোল্ডারে যান এবং `index.html` ফাইলটি যেকোনো ব্রাউজারে খুলুন।

## সতর্কতা (Notes)

- ওয়েবসাইটের কপিরাইট শুধুমাত্র ব্যক্তিগত/শিক্ষামূলক ব্যবহারের জন্য।
- সার্ভারকে অতিরিক্ত লোড না দিতে `time.sleep()` রাখা হয়েছে।
- কিছু ডায়নামিক কন্টেন্ট (জাভাস্ক্রিপ্ট দিয়ে লোড হয়) পুরোপুরি কাজ নাও করতে পারে।
- প্রয়োজনে `download_full_site.py` এর ভিতরে sleep টাইম বাড়াতে পারেন।
